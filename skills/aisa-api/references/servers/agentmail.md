# AIsa AgentMail

Email inboxes for agents through AIsa: create a real sending and receiving address, read messages and conversation threads, search them, stage drafts and send them, forward, reply and reply-all, manage labels and allow/block lists, and read delivery events. Inboxes are shared across callers on this deployment — every write tool says so, and the six that send mail say it cannot be recalled.
