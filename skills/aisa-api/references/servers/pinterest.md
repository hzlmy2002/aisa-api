# AIsa Pinterest

Read public Pinterest through AIsa: search pins by keyword, fetch one pin's details and engagement counts, page through a board's pins, and list a user's boards. Every tool accepts trim=true, which measurably shrinks responses (up to 18x) and is documented per tool.


4 operations. Follow only the needed detail links, then call use; get_details is a fallback.

- [get_pinterest_board](../operations/get_pinterest_board.md) — Board
- [get_pinterest_pin](../operations/get_pinterest_pin.md) — Pin
- [get_pinterest_search](../operations/get_pinterest_search.md) — Search
- [get_pinterest_user_boards](../operations/get_pinterest_user_boards.md) — User Boards
