# Third-party workflow acknowledgements

Two local workflows adapt ideas and guidance from AISA-skills. All execution uses this package's existing MCP operations; upstream Python runtimes and transport code are not bundled.

- `aisa-creator-outreach-list`: [kol-creator-discovery](https://github.com/AISA-skills/marketing-skills/tree/e85406b51fca084908e3a06aa62f574c74325535/kol-creator-discovery). Adapted to reuse returned emails and fetch only missing contact data by default.
- `aisa-recent-topic-research`: [last30days](https://github.com/AISA-skills/search-research-skills/tree/800e99b62d33f1e1a30525562784ed914df31729/last30days). A new compact workflow inspired by recent multi-source research; direct coverage is limited to Web, X and Reddit. External provider clients, scoring pipelines and background monitors are not bundled.
